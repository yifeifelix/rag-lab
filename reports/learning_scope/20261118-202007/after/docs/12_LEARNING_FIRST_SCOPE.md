# 学习主线优先：范围调整审计

日期：2026-11-18。用户明确确认：项目以 RAG 学习路径与 Lab 为主。此前把审计修复扩展成工程交付平台，产生了范围偏移。本轮收回默认复杂度，保留已有正确性修复与可选专题。

## 当前目标与成功标准

主线是“理解链路 → 单变量实验 → 原句核查 → 失败分析”。学习者能够解释每一步，完成一份有假设、变量、证据和局限的记录，比集成组件数量或合成并发数字更重要。求职与 Freelance 演示是学习成果的用途。

主线包含七课：最小链路、分块、检索、RRF、重排、拒答、评估。每课提供概念、动手任务、完成标准和源代码入口。完成勾选为浏览器本地自评，仅保存课号，不自动认证知识掌握。

## 实际调整

| 部分 | 当前行为 |
| --- | --- |
| 首页 | 默认进入学习路径，按七课开始练习 |
| 链路观察 | 初始 BM25、关闭特征重排和答案缓存；示例与实际演示语料匹配 |
| 单变量 Lab | 同一语料快照和问题，选择 A/B；支持分块、检索、重排、top-k、拒答阈值 |
| 实验约束 | 固定本地 SVD、特征实现和抽取回答；不调用远程模型，不读校准、不写原索引、不改文档；显示其余主要配置 |
| 分块观察 | 原文、child / 检索文本、parent / 返回上下文并列可查；字符长度明确标注 |
| 实验记录 | 先写假设，查看证据与回答后记录观察；owner 可显式保存运行到私有目录；页面观察笔记不会自动保存 |
| 进阶入口 | 批量评测、并发和附加原理默认收起；真实模型、图、压缩、校准、Qdrant 为自选专题 |
| 默认启动 | OrbStack 基础与模型配置均不自动校准，默认不加载历史校准文件 |
| GitHub 检查 | push / PR 默认只做源码检查、测试、Python 包构建；Docker / Qdrant 检查需手动触发并启用 integration |
| 既有修复 | 原文保真、引用/压缩一致性、拒答动作、开发/测试隔离、日志和路径策略保留 |

单变量的含义是只改声明的配置因素；分块改变会自然改变局部 SVD 的拟合输入和块数量，不能宣称所有中间表示固定。重排练习的两个配置都固定为 hybrid_rrf，差别只有开关。单条查询的耗时不是速度基准，证据排名变化也不等于回答正确。

## 新增接口与数据边界

- `GET /api/v1/learning`：七课与进阶专题。
- `GET /api/v1/learning/chunks?doc_id=...&strategy=...`：只读分块预览。
- `POST /api/v1/learning/compare`：声明一个变量和两个不同有效值；默认不保存。
- tester 可学习、预览和运行不保存的 Lab；保存运行需 owner。原有文档写权限不变。
- 同时只运行一个 Lab 请求，忙时返回 429；计算在有界线程池执行。
- 可写文件继续位于配置的 Data 根；不增加服务、依赖或默认模型下载。

## 保留内容与暂缓事项

代码和历史证据保留，不做破坏性删除。神经模型、Qdrant、置信度校准、缓存/并发与交付演示仍可作为选修，但不再是完成第一条学习链路的前置条件。

此前约 35% 的误拒答是历史特定校准配置在已见题集上的诊断，不是当前默认学习模式的成绩。本轮不重新包装旧题集、跑满分对照或宣称新质量提升；优先验证学习流程是否能实际使用。已有语料/标签仍需独立人工审核。

历史 09 / 10 号报告记录当时的工程工作；其默认自动校准、入口次序和默认 CI 运行范围以本报告为准。新的源码哈希和检查结果写在 `reports/learning_scope/`，不覆盖旧审计快照。
