Data Scientist Portfolio & Interview Highlights

        
    
          
  • Ablation Rigor: 先完成单变量练习，再在明确的数据划分上做批量对照；可查看 500x Bootstrap 95% CIs and descriptive paired bootstrap differences; independent human review remains pending.
    • 
          
  • OOV Failure Mode: Demonstrated why pure Dense vectors fail on exact codes (ERR_QDRANT_5032, SOC2-CC6.7) and why single-word OOV collisions require vocabulary coverage gating.
    • 
          
  • Concurrency Mechanisms: Eliminates duplicate cold LLM calls via Singleflight, serves paraphrases via L2 cosine >= 0.90, and prevents overload via bounded semaphores + circuit breakers.
