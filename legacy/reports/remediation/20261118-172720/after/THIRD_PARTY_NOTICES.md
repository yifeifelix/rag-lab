# Third-party materials

The MIT license covers this project's original code and documentation.

`data/python_support/documents.jsonl` contains excerpts of installed CPython
3.12 asyncio docstrings. These materials retain the Python Software Foundation
and other applicable CPython notices in
[`data/python_support/PYTHON_LICENSE.txt`](data/python_support/PYTHON_LICENSE.txt).
Per-document provenance and source hashes are recorded in the dataset. Audit
snapshots or evaluation outputs reproducing these excerpts retain those notices.

Python packages and optional downloaded models retain their own licenses.
Dependency locks do not relicense their contents. The default container uses
synthetic demonstration documents; pretrained model weights are not bundled.
