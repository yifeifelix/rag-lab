# 学习路线：看懂链路，做实验，解释失败

以应用首页七课为主线。每课执行“先猜 → 运行 → 找原句 → 写观察 → 解释局限”，能解释后再勾选自评完成。不要用“接入了几个框架”衡量进度。

## 1. 跑通最小链路

打开“链路观察”，保持 BM25、关闭重排与缓存，问当前 Cedar EU 恢复目标。打开完整证据，找到对应原句，再问一个资料没有提供的问题。

画出“原文 → 分块 → 检索 → 回答 → 引用”。阅读 `pipeline.py` 与 `security.py`。默认答案是抽取式，向量基线是 TF-IDF + SVD。

产出：一条有答案、一条无答案的查询记录，以及你对每一步输入和输出的说明。

## 2. 分块与上下文

在 Lab 底部选择同一篇文档，预览 fixed、recursive、parent_child；再用单变量对照比较 fixed / parent_child。长度以字符计，不是 token。

阅读 `chunking.py`。比较原文、child、parent，检查否定条件、表格与关键数值是否被切开。改变分块也会改变本地 SVD 的拟合输入，不应把观察解释成孤立的预训练 encoder 效果。

产出：一个边界问题和一个更完整的上下文例子。

## 3. BM25 与向量检索

固定其他配置，只比较 bm25 / dense。分别用精确术语、自己的改述、短查询和无关问题。

阅读 `embeddings.py`、`retrieval.py`。手算一小段 BM25 和余弦相似度，说明局部 SVD 与预训练 bi-encoder 的区别。

产出：两种检索各一个失败例子；允许简单方法在你选的问题上更好。

## 4. RRF 排名融合

在同一问题上比较 bm25 / hybrid_rrf，观察新增候选与顺序。手算两条排名的加权 RRF。

产出：解释为何不同算法原始分数不能直接相加，并说明这一条问题中融合是否值得。

## 5. 重排

Lab 自动固定 hybrid_rrf，再对照特征重排的开关。核查第一条证据、最终引用和回答是否变化。

阅读 `reranker.py`。当前人工特征不是神经 cross-encoder。真实模型对照是主线完成后的独立专题，不需要为了上第一课下载模型。

产出：一条排序改善或回归的记录，不只比较总分。

## 6. 拒答与置信度

对有答案、无答案、短查询分别比较 0.22 / 0.50。人工判断是否应该回答。

原始相关性不是正确概率。阈值可能减少错误作答，也可能增加误拒答。主线不自动应用校准；进阶时再学习 `study.py` 的按组交叉拟合和代价曲线。

产出：错误作答/错误拒答的两个例子，说明你愿意接受怎样的取舍。

## 7. 评估与失败分析

对多跳问题比较 top-k 1 / 5，逐个核对必要事实。自己编写至少五道问题并标注支持句、可回答性与预期答案，保留一条失败例子。

阅读 `evaluation.py`。Recall 命中文档不代表回答正确；词项覆盖不能识别关系颠倒。没有标注的指标为 null。一次实验不能得出泛化或速度结论。

需要汇总时运行 `scripts/workbench study compare`。只在 dev 上挑参数；最终测试先冻结配置。当前历史题目由实施代理编写并已见过，需要独立用户题才能形成新的外部效果证据。

产出：一份含假设、唯一变量、证据、观察与局限的实验记录，能够向另一个人解释。

## 自选进阶

预训练 embedding / cross-encoder、压缩 / 扩展 / 共现图、校准、缓存与并发、Qdrant 与交付展示。每次选择一个专题，不为完成学习主线先建设生产平台。万次协程实验是附加机制实验，不是项目的成功标准。
